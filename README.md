# CWTools MD Edition

CWTools MD Edition combines the VS Code extension and Rust language engine for
Paradox Interactive game modding in one repository.

- [`extension/`](extension/) contains the extension host, webview, tests, and
  checked-in VSIX package inputs.
- [`engine/`](engine/) contains the Rust workspace, including `cwtools-server`
  and the standalone `cwtools` CLI.
- [`docs/`](docs/) contains the extension and engine documentation.

Start with the [extension guide](docs/extension/README.md), the
[engine overview](docs/engine/README.md), or the
[contributor guide](docs/CONTRIBUTING.md).
